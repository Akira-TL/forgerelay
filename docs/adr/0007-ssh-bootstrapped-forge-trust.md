# 通过安全外壳（SSH）引导实例信任并复用模型上下文协议（MCP）入口

锻造中继（ForgeRelay）之间的长期认证采用独立于宿主开放授权（OAuth）的实例信任（Forge Trust），并由用户在命令行（CLI）执行 `forgerelay auth user@host`，借助已有的安全外壳（SSH）权限把新的信任记录写入远端实例。发起实例生成高熵信任令牌，只把令牌哈希写入执行实例，本地保存可出站使用的令牌；每条信任关系都是有方向的并可独立轮换或撤销。实例间实际工作通信继续复用现有模型上下文协议（MCP）服务入口，由认证结果区分宿主身份和受信实例身份；只有受信实例身份可以携带锻造中继内部的可信上游会话信息。这样避免为实例接力再维护一套独立网络端点，也避免让机器间连接模拟需要人工网页批准的开放授权流程。

## 未采用方案

- 不让模型提供实例地址、端口、认证头或令牌，避免模型把锻造中继变成任意网络访问入口。
- 不要求实例之间执行浏览器式开放授权（OAuth）流程，因为机器间长期连接不应依赖人工重定向和授权页面。
- 不单独增加接力专用模型上下文协议（MCP）端点；认证主体已经足以区分普通宿主请求与受信实例请求，复用一个入口可以减少服务、代理和部署配置的分叉。
