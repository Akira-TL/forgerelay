# ForgeRelay 0.6.0

ForgeRelay 0.6.0 promotes the validated `0.6.0-rc.1` line to the stable channel. No product code changed after RC1; this release freezes the current ChatGPT MCP App experience as the 0.6.0 baseline and moves stable installs from `0.5.6` to `0.6.0`.

## Highlights

### Unified ForgeRelay Panel

One Host Turn now uses one coherent ForgeRelay Panel. Workspace context remains visible above a collapsible Activity area, while durable Activity state, lazy detail, and Bash output stay owned by ForgeRelay rather than by the Host UI.

Host Turn scoping prefers Host conversation metadata, then the MCP transport session, then the current connection, which keeps Workspace-specific Activity state usable across ChatGPT, Inspector, and ordinary MCP hosts without merging unrelated Workspaces.

### Virtual Skill namespace

Skills are advertised by name and loaded through `skills://<name>`. Files bundled with an activated Skill remain available below that virtual namespace, while normal Agent-facing metadata no longer needs to expose the Skill's physical filesystem path.

### Routed and multiple public base URLs

`publicBaseUrl` supports one routed URL or an ordered list. Route prefixes are preserved through OAuth and MCP App resource generation, every configured hostname participates in the Host allowlist, and the ordered URL set participates in App resource identity and CSP metadata.

### Efficient long-running process waits

Agents can reuse a returned `processId` and request one bounded wait with `bash(action="process", ..., yieldTimeMs=...)`. Finishing during that window returns the final result immediately; otherwise the same process remains alive and the same identifier is returned. This keeps feedback waiting separate from the independent execution `timeoutMs` deadline.

### Better local Host acceptance

The source checkout includes the dedicated `127.0.0.1:7677` MCP Inspector/debug workflow for exercising the real HTTP, OAuth, MCP, App metadata, and transport-session path without touching the normal product port.

## Stable channel

- Git tag: `v0.6.0`
- npm version: `0.6.0`
- npm dist-tag: `latest`
- GitHub Release: stable

Users on the stable channel can install or upgrade with:

```bash
npm install -g @akira-tl/forgerelay@latest
```

The previously published `0.6.0-rc.1` remains available on the prerelease history, but 0.6 development now continues from this stable baseline.
