# ForgeRelay 1.0.1

ForgeRelay 1.0.1 is a small observability and lifecycle-logging fix.

## Fixed

- Capability pretty logs now include the Capability name and `describe`/`run` action instead of degrading to a generic `capability -> ok` line.
- Workspace lifecycle logs now preserve operation identity and cover Composite member changes plus checkout/Composite close and delete paths consistently.
- Composite-owned `workspace.tasks` success and failure logs now carry the owning Composite Workspace identity without exposing arbitrary Capability arguments or Task content.
- Closed checkout Workspaces can still be deleted through historical aliases after the logging changes, preserving the existing lifecycle contract.

## Verification

The patch is released only after the full local test/build/typecheck/architecture/release gate passes on a clean release tree. The `v1.0.1` tag then runs the authoritative Linux, macOS, and Windows Release workflow before publishing the verified npm artifact and GitHub Release.
