# ForgeRelay 1.2.4

ForgeRelay 1.2.4 是一个 managed-worktree 语义与 Workspace Panel 一致性补丁版本。它把 pinned baseline 与最终 integration target 正式解耦，并完成本轮 Workspace Panel 长路径与身份色视觉收尾；同时继续压缩正式发布 CI 的重复工作。

## Managed worktree

- `baseRef` 现在可以使用任意 Git commit-ish，而不再要求必须是本地 branch；managed worktree 可以从历史 commit、tag 或其他可解析 ref 启动。
- pinned baseline 与最终 integration target 独立保存。不同 pinned baseline 不会错误复用为同一个 managed Workspace，reopen / recovery / rebase / close 仍保留正确的 baseline metadata，并最终集成到配置的 target branch。
- fast-forward-only close 在 target 已经分叉时继续明确拒绝；完成 rebase 后可以安全 close/integrate，不创建临时 baseline branch，也不会污染 source checkout。

## Workspace Panel

- Root、Source checkout 等长路径在详情区正常换行，不再用省略号隐藏关键路径尾部。
- pretty log 中的 Workspace 项目名与 Workspace Panel 共用同一个身份色分配；Panel 顶部及 Root、Mode、Instructions、Skills、Agents 等行的 SVG 图标统一跟随当前 Workspace 身份色。
- Workspace 身份色池扩展为 14 个普通 / bright 前景色槽位。单个 ForgeRelay 进程内前 14 个不同 Workspace 显示名保证不重复，第 15 个开始才允许复用；POSIX 与 Windows 风格路径使用同一名称归一化规则。

## Release / CI

- 进一步拆分可独立并行的 CI 验证，并复用安全的 pinned npm / packaged shell runtime 状态，减少 Windows 与跨平台正式发布矩阵中的重复准备工作。
- 正式发布仍只由稳定版本 tag 触发；Linux、macOS、Windows 权威矩阵全部通过后才允许 npm publication 与 GitHub Release creation。

## 验收

- managed-worktree 的真实 `7677` / `7678` 路径已验证 raw SHA open、pinned reuse separation、fast-forward refusal、rebase + close、reopen、recovery metadata 与 clean source checkout。
- Workspace Panel 在最新 `7677` debug 实例完成用户可见验收，包括长路径换行、14 色身份分配及 Panel 全部相关 SVG 的身份色统一。
- 相关 logger / Workspace tests、App build、TypeScript typecheck 与 diff checks 均已通过；正式 tag 仍需通过仓库定义的 release verification 与云端 Linux/macOS/Windows 发布矩阵。
