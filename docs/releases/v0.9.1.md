# ForgeRelay 0.9.1

ForgeRelay 0.9.1 完成 0.9 系列的 managed-worktree 恢复阶段：在 0.9.0 只读诊断基础上，`workspace.recovery` 现在可以在安全条件可证明时修复缺失 backing，并清理当前 Workspace 所属的 Git administrative residue。

## 主要变化

- `workspace.recovery { operation: "repair" }` 只从原有 `forgerelay/*` managed branch 重建 active Workspace 的 execution backing，保留未合并提交和 persistent `workspaceId`。
- `workspace.recovery { operation: "cleanup" }` 只处理当前 persistent Workspace 可证明归属的 stale worktree registration；closed Workspace 的残留 managed branch 仅在 Git 证明已并入持久化 target branch、且没有 active backing、其他 worktree registration 或其他 persistent Workspace 持有时删除。
- unique/unmerged commits、branch mismatch、source/target identity 不明确、active backing 或其他 ownership 歧义均保持不变并返回 `manual-intervention`，不执行强制 merge、reset、prune 或全局扫描。
- Relay recovery 仍在 Execution ForgeRelay 执行；Composite Workspace 必须显式指定 member。canonical nine Core MCP tools 保持不变。

## 验证

发布前本地验证覆盖公共 `workspace.recovery` Capability、真实临时 Git repository/worktree、Relay 与 Composite 路径，并通过完整 `npm test`、build、architecture check、typecheck、release metadata check 与 `git diff --check`。最终发布以 tag 触发的 Linux、macOS、Windows 云端验证为准。
