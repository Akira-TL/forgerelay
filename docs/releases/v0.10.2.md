# ForgeRelay 0.10.2

ForgeRelay 0.10.2 adds first-class Windows PowerShell 5.1 (`powershell.exe`) support and completes the Windows ConPTY lifecycle hardening carried forward from PowerShell 7 acceptance.

## 主要变化

- Agent commands and Hooks can now select a pinned Windows PowerShell 5.1 Command Shell Runtime. ForgeRelay probes the executable, preserves the `powershell` family and 5.1 identity, and rejects incompatible PowerShell versions instead of silently changing command language.
- Pipe and PTY execution cover Windows PowerShell 5.1 stdin, resize, background completion, timeout, interrupt, durable output, Unicode, native exit propagation, error semantics, and child-process-tree cleanup while retaining 5.1-specific quoting and syntax behavior.
- The packaged Windows acceptance path packs and installs the npm artifact, launches the generated ForgeRelay shim through Windows PowerShell 5.1, and verifies that Host-visible shell identity/version and executed language remain Windows PowerShell 5.1.
- Windows ConPTY teardown now avoids unsupported signal forwarding, explicitly cleans the child process tree, and releases node-pty input/output resources after PTY exit. Windows PowerShell text I/O is normalized to UTF-8 so Unicode and completion behavior are stable.

## 验证

The Windows release gate builds ForgeRelay and runs both native PowerShell 7 and Windows PowerShell 5.1 acceptance on `windows-2022`. The 5.1 suite exercises real Agent, Hook, pipe, PTY, child-process, durable-output, and packed npm invocation paths. Linux and macOS remain part of the authoritative release CI matrix to cover Bash and cross-platform regressions.
