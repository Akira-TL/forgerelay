# ForgeRelay 0.9.3

ForgeRelay 0.9.3 完成 0.9 系列的安全 checkpoint restore 阶段：`workspace.checkpoint` 现在支持先检查、再恢复的乐观并发流程，在恢复前确认工作区内容没有被用户、IDE 或其他工具继续修改。

## 主要变化

- 新增 `restore.preflight`，返回选中 checkpoint 的 immutable Git tree identity、当前 Git-visible working snapshot identity 和有界 restore summary，不修改文件。
- 新增 `restore`，要求调用方回传 preflight 的 `expectedCurrentSnapshot`；ForgeRelay 在实际 apply 前重新计算当前 snapshot，不一致时在零 restore mutation 的前提下拒绝执行。
- 成功 restore 只恢复 Git-visible working-tree 内容，不移动 branch `HEAD`、不 rewrite history、不 hidden merge/rebase、不 auto-commit，也不使用 `reset --hard` 语义。
- ignored files 保持在 checkpoint/restore 内容模型之外；0.9.3 明确只承诺 content-state，不恢复或重建历史 staged-versus-unstaged 划分，真实 Git index 不由 restore 重写。
- restore 与 managed-worktree recovery 保持独立；Relay 在拥有 Workspace 的 Execution ForgeRelay 执行，Composite 必须显式指定 member。

## 验证

发布前公共 Capability 测试覆盖 addition、modification、deletion、rename、binary、ignored-file preservation、HEAD/index 不变，以及 preflight 后外部编辑导致的零写入失败；同时覆盖 managed-worktree recovery 独立性、Relay 和 Composite 路由。完整 `npm test`、build、architecture check、typecheck 和 `git diff --check` 均通过。最终发布以 tag 触发的 Linux、macOS、Windows 云端验证为准。
