# ForgeRelay 0.10.1

ForgeRelay 0.10.1 adds first-class native PowerShell 7 (`pwsh`) execution on Windows without changing the canonical nine Core MCP tools.

## 主要变化

- Agent commands, Hooks, and PTY sessions now use one fixed `pwsh` Command Shell Runtime. Non-TTY execution uses `-NoProfile -NonInteractive`; PTY execution keeps the same executable and still suppresses the user profile.
- ForgeRelay probes the selected `pwsh` runtime version, requires PowerShell 7 or newer, and exposes the version and PowerShell capabilities in Agent/doctor runtime identity.
- PowerShell-native environment, pipeline, native argv/quoting, redirection, error, exit-code, background, timeout, interrupt, and blocking Hook semantics are covered by Windows cloud acceptance.
- `forgerelay init` can seed a deeper editable PowerShell Skill from the exact release tag into the ForgeRelay config Skills directory. Prompt templates remain outside the npm package and existing user edits are preserved.

## 验证

The Windows release gate builds ForgeRelay, executes real Agent and Hook paths through `pwsh`, exercises PTY/process lifecycle semantics, packs the npm artifact, installs it into an isolated prefix, and invokes the generated `forgerelay.ps1` launcher to verify launcher affinity plus Host-visible PowerShell 7 identity/version. Linux and macOS remain part of the same authoritative release matrix.
