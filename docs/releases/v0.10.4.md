# ForgeRelay 0.10.4

ForgeRelay 0.10.4 closes the P3 native-shell release line by making shell identity follow the actual execution owner across Relay and Composite Workspaces and by aligning the remaining product surface with the effective Command Shell Runtime.

## 主要变化

- Relay now projects shell/platform identity from the Execution ForgeRelay that owns the Workspace rather than from the Gateway. Composite members keep independent shell identities, so mixed Linux/Windows and mixed `pwsh`/Windows PowerShell/`cmd.exe` topologies do not inherit one incorrect global command language.
- The public Core tool name `bash` remains stable for Host compatibility, but Agent context and tool descriptions no longer promise Bash syntax when the effective runtime is PowerShell, cmd, zsh, or fish.
- Doctor, Workspace UI, Instructions state, and product documentation now report the actual Command Shell Runtime, executable, selection source, compatibility boundary, and relevant shell-guidance state instead of presenting Windows execution as Bash-only.
- Explicit non-Bash POSIX selections keep their real shell identity and receive a visible compatibility boundary rather than silent Bash substitution.
- Packaged Windows acceptance installs the real npm artifact into an isolated prefix and validates PowerShell 7, Windows PowerShell 5.1, and `cmd.exe`, including editable shell Instructions and the elevated-startup safety contract.

## 验证
