# ForgeRelay 0.10.5

ForgeRelay 0.10.5 is a small Skill-discovery compatibility fix. It removes ForgeRelay-side handling of the legacy `disable-model-invocation` Skill frontmatter so every discovered Skill remains visible to the Agent for model-side matching.

## 主要变化

- `open_workspace` now exposes every discovered Skill's `name` and `description` to the Agent instead of filtering Skills marked with `disable-model-invocation: true`.
- ForgeRelay no longer carries `disableModelInvocation` through its Skill model, bootstrap fingerprint, server/Composite projections, or dynamic Skill metadata updates.
- Existing Skill files may keep the old `disable-model-invocation` frontmatter without migration; ForgeRelay ignores the field and still advertises the Skill normally.
- Skill loading remains lazy: the Agent chooses a matching Skill and loads `skills://<name>` before ForgeRelay activates access to that Skill's internal resources.

## 验证

The change passed focused Skill/open-workspace tests, TypeScript validation, the full local test/build gate, architecture checks, Wiki source checks, and `git diff --check` before release preparation. The stable release remains gated by the tag-triggered authoritative Linux/macOS/Windows Release workflow before npm and GitHub Release publication.
