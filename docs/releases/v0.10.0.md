# ForgeRelay 0.10.0

ForgeRelay 0.10.0 establishes the P3 Command Shell Runtime foundation before native PowerShell/cmd execution work begins.

## 主要变化

- Added one server-lifetime Command Shell Runtime identity shared by Agent commands and Hooks, with launch-shell affinity, recorded fallback, explicit pinned family/executable selection, and owner-visible doctor output.
- Added editable shell Instructions for PowerShell 7, Windows PowerShell 5.1, cmd, zsh, and fish. `forgerelay init` fetches exact-release-tag defaults into the user config directory, preserves existing edits, and exposes loaded/disabled/unavailable state through the existing Workspace Instructions UI and context-delta path.
- Added a cross-platform elevated-runtime startup gate. Elevated or unverified system-level execution is refused by default; intentional use requires the invocation-scoped `--allow-elevated` acknowledgement and always emits mandatory Agent safety context.

## 验证

Fresh packed `0.10.0` acceptance installed the generated npm artifact into an isolated prefix, exercised `forgerelay init` with a pinned zsh-family executable path, confirmed pre-tag exact-version guidance fetch failure is explicit and does not create fake content, and verified real elevated refusal/`--allow-elevated` startup behavior on Linux without touching port 7676. Final release verification remains the tag-triggered Linux, macOS, and Windows cloud matrix.
