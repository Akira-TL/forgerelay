# ForgeRelay 1.3.1

ForgeRelay 1.3.1 是针对已复用 Workspace 并发打开路径的稳定性热修复。多个重叠的 `open_workspace` 请求此前可能同时重建同一个可变 Workspace context，导致 Workspace instruction presentation 在请求竞争时被清空或重复追加。

## 修复

复用 Workspace 的 context rebuild 现在按 `workspaceId` 合并同一时刻的在途重建。重叠的 Host 请求共享同一个重建结果，不再同时清空和重新填充 instruction / Skill / profile 等 Workspace context 状态。

conversation-specific context delivery、resource delta 领取和后续 presentation 仍在共享重建完成后分别处理，因此本修复不会把不同会话的 delivery 状态合并在一起。

本版本同时加入 MCP 层并发回归覆盖：同一会话对同一个已打开 Workspace 发起多次并发 `open_workspace` 时，配置型 Shell Instruction 必须保持单一、已加载的 presentation。

## 兼容性

1.3.1 不新增配置字段，不修改 Config System v2 schema，不改变 MCP Core tool surface，也不需要迁移。它仅修正复用 Workspace 的并发重建协调。
