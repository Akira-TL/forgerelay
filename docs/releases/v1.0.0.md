# ForgeRelay 1.0.0

ForgeRelay 1.0.0 marks the current product and protocol behavior as the stable release baseline. It does not introduce a migration from 0.10.5; the release promotes the already-shipped Workspace, execution, recovery, Relay/Composite, LSP, Hook, Task, Activity/Audit, and cross-platform shell work into the 1.x line.

## Highlights

- Stable public baseline for the current MCP Core tool surface, CLI behavior, persistent Workspace lifecycle, managed-worktree finalize flow, and Capability Gateway.
- Native Command Shell Runtime coverage across Linux/macOS POSIX shells and Windows PowerShell 7, Windows PowerShell 5.1, and `cmd.exe` remains part of the supported release contract.
- README and GitHub Wiki were rebuilt around first-run setup and normal usage, with the new ForgeRelay branding and Activity Panel preview.
- Existing MIT attribution to Waishnav/devspace remains preserved in `LICENSE`, `NOTICE.md`, repository history, and release provenance checks.

## Upgrade notes

No configuration or state migration is required from 0.10.5. Existing ForgeRelay config, Workspace state, Tasks, checkpoints, managed worktrees, Skills, Hooks, Relay aliases, and Subagent profiles continue to use the current formats.

## Verification

The release is prepared only after the full local test/build/typecheck/architecture/Wiki/release gate passes on a clean tree. Publication remains gated by the `v1.0.0` tag workflow, which runs the authoritative Linux, macOS, and Windows CI matrix before publishing the verified npm artifact and GitHub Release.

- npm version: `1.0.0`
- npm dist-tag: `latest`
