# ForgeRelay 0.8.10

ForgeRelay 0.8.10 focuses on keeping long-lived Agent workspaces current without flooding context, while making Language Server support and setup more self-contained.

## Highlights

- **Live Workspace context:** changes to loaded Workspace instructions and Skills are delivered as bounded deltas after the Workspace is already open instead of requiring a restart or repeating the full bootstrap.
- **Managed TypeScript code intelligence:** when explicitly enabled by the user, ForgeRelay can install its own TypeScript Language Server runtime, wire the private `tsserver`, refresh the running service without restarting ForgeRelay, and return fresh diagnostics after file mutations.
- **Proactive Workspace Tasks:** Agent guidance now treats `workspace.tasks` as durable continuation state for multi-step or cross-session work, while explicitly avoiding a mechanical Task query on every `open_workspace` call.
- **Cleaner Agent process environment:** non-interactive Agent Bash execution is isolated from the user's interactive shell customizations, and SSH-assisted authentication no longer depends on sourcing user shell rc files.
- **Clearer setup boundaries:** setup now distinguishes local/SSH-only access from network-exposed ForgeRelay configuration.

## Additional changes

- Increased the default foreground process wait to reduce unnecessary background handoff for ordinary commands.
- Retired the bundled `subagent-delegation` Skill; required delegation behavior remains in the Subagent capability contract and guide.
- Stabilized Language Server cancellation, delayed push diagnostics, managed runtime fingerprinting, and mutation-diagnostics coverage.
- Hardened the release path with pinned npm tooling and mandatory dedicated release notes before a release tag can be published.

## Compatibility

Managed Language Server installation remains opt-in. Existing external Language Server discovery and explicit project/global server configuration continue to work, and ForgeRelay does not install an LSP unless the user has enabled managed installation.

Workspace context refresh remains bounded: unchanged bootstrap content is not resent, and Task bodies remain progressively disclosed only when relevant.
