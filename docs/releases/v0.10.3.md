# ForgeRelay 0.10.3

ForgeRelay 0.10.3 promotes Windows `cmd.exe` to a first-class Agent and Hook runtime and completes its native pipe, PTY/ConPTY, Instructions, and packaged npm `.cmd` launcher acceptance.

## 主要变化

- Agent commands and Hooks can select and preserve a first-class `cmd` Command Shell Runtime instead of silently falling back to PowerShell or Bash. Host/Agent guidance exposes the cmd identity and the required `%NAME%`, `%ERRORLEVEL%`, quoting, escaping, chaining, redirection, parentheses, and delayed-expansion semantics.
- cmd execution now has Windows acceptance across pipe and PTY/ConPTY paths, including stdin, resize, background completion, timeout, Ctrl-C interruption, durable output, Unicode, exit-code propagation, and child-process-tree cleanup while reusing the shared Process Manager.
- Interactive cmd sessions preserve the raw `cmd.exe /S /C` Windows command line when handed to node-pty, preventing CommandLineToArgvW-style re-escaping from changing cmd quoting or exit behavior.
- The packaged Windows acceptance path creates a real npm tarball, installs it into an isolated prefix, launches the generated `forgerelay.cmd` shim, and verifies that the packaged CLI reports and uses `cmd.exe` as the launcher/runtime.

## 验证

The dedicated Windows shell gate runs the standard command-runtime suite plus PowerShell 7, Windows PowerShell 5.1, and cmd.exe packaged acceptance on `windows-2022`. The authoritative 0.10.3 release CI also keeps Linux and macOS in the matrix so the existing Bash and cross-platform runtime contracts remain protected.
